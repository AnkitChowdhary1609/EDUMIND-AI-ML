📐 DECISIONS.md — Engineering Log

1. Strategy & Rejected Alternatives

Why an Interactive Live Showcase over Static Mockup Screenshots?
A static screenshot claims that a product works; an interactive widget proves it in under 3 seconds. By exposing a real-time mathematical risk evaluation engine driven by client-side JS, visitors immediately experience the core product utility without a single API call.

Why 100% Honest Data & Zero Synthetic Social Proof?
Fake testimonials create cognitive friction for technical evaluators. Every metric (1,000 records, 94.2% accuracy, 4 clusters) is verifiable from the real benchmark dataset and production models.

2. Time-Limit Trade-offs & 1-Week Roadmap

Trade-off made: Used client-side mathematical approximation for the hero sandbox preview — eliminates network latency (<150ms) and removes external server dependency on page load.

With a full week: Expose a FastAPI ONNX runtime microservice, build Three.js WebGL 3D point-cloud cluster exploration, add real-time resume PDF ATS scoring directly in-page.

3. AI Tool Usage & Personal Verification

AI tools generated baseline CSS layout keyframes and prompt structure. I personally hand-verified the multi-variable prediction formula, CSS breakpoints at 390px / 768px / 1440px, and deliberately stripped back excessive animations to keep motion purposeful and restrained.
